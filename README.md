# RetroRevive 
Plataforma web enfocada en la venta de consolas reacondicionadas, videojuegos clásicos y servicios de reparación técnica especializada.

https://retrorevive-web.pages.dev

## Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript Vanilla
* **Diseño UI/UX:** Figma
* **Base de Datos:** PostgreSQL / SQL Server (Fase de integración)
* **Despliegue:** Cloudflare Pages

## Características Principales
* Catálogo dinámico filtrable por marca (Nintendo, PlayStation, Sega, Xbox).
* Sistema de carrito de compras y revisión de pedidos.
* Cotizador de servicios técnicos (Mantenimiento, Restauración Estética, Mods, Láser).
* Interfaz con temática retro y animaciones arcade.
